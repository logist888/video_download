# video for me

Расширение Chrome (Manifest V3), написанное с нуля. Находит медиафайлы на странице и скачивает их.

## Установка
1. Откройте `chrome://extensions`, включите «Режим разработчика».
2. «Загрузить распакованное расширение» и выберите папку `video-for-me`.
3. Запустите видео на странице, нажмите на значок расширения, выберите качество и «Скачать».
4. В открывшейся вкладке нажмите «Выбрать файл и начать». Файл пишется прямо на диск, поэтому большие видео не забивают память.

## Как ищет видео
- Перехватывает сетевые запросы страницы (MP4, WebM, HLS, DASH).
- Анализирует HTML: теги video, audio, source, мета-теги, ссылки, JSON и тексты скриптов (в том числе с экранированием `\/`), а также историю уже выполненных запросов страницы. Поэтому видео находится и без запуска воспроизведения, и на странице, открытой до установки расширения.
- При каждом открытии окна расширения страница сканируется заново.

## Что поддерживается
- Прямые файлы: MP4, WebM, MOV, MP3, M4A.
- HLS (.m3u8): выбор качества, шифрование AES-128, параллельная загрузка сегментов. Результат сохраняется как `.ts` (или `.mp4` для fMP4).
- DASH (.mpd): выбор качества видео и аудиодорожки, SegmentTemplate (в том числе SegmentTimeline), SegmentList и одиночный файл по BaseURL. Берётся самый длинный период манифеста.
  Видео и аудио в DASH лежат отдельно, поэтому сохраняются двумя файлами (`имя.video.mp4` и `имя.audio.m4a`), у каждого своя кнопка. Объединить их можно командой:

```
ffmpeg -i "имя.video.mp4" -i "имя.audio.m4a" -c copy "имя.mp4"
```

## Не поддерживается
- DRM (Widevine, FairPlay, SAMPLE-AES, CENC) и защищённые потоки.
- Прямые трансляции (live) DASH.
- Ссылки, требующие специальных заголовков (Referer, куки с проверкой на сервере).
